# Práctica guiada · Tema 4 · Simulacros de primer parcial

Dos parciales completos, con el mismo formato que el Tema B de la guía (3 ejercicios, 1,5 horas, aprobás con 2 de 3):

| Simulacro | Ej. 1 (POO) | Ej. 2 (Patrones) | Ej. 3 (Refactor SOLID) |
|---|---|---|---|
| `simulacro-tema-A-cine/` | Abstracta, `static`, getter, constante de clase | **Observer + Adapter** | **SRP + OCP** |
| `simulacro-tema-C-viajes/` | Abstracta, getter/setter, `static`, `super` | **Singleton + Factory** | **LSP + ISP** |

Cómo hacerlos:
1. Poné un cronómetro de 90 minutos.
2. Creá un repositorio Git y seguí los puntos de control (`chore: configuración inicial`, etc.).
3. Trabajá en `inicio/`. Al terminar, completá un `ENTREGA.md` con la plantilla `../plantilla-ENTREGA.md`.
4. Corregite con `solucion/` y su `SOLUCION.md`.
