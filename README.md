# Repaso TLP IV · Parcial

Material de estudio para el parcial de **Taller de Lenguajes de Programación IV**: guías desde cero, ejercicios con soluciones explicadas y simulacros.

| Carpeta | Qué hay |
|---|---|
| [Parcial-TLP-IV/](Parcial-TLP-IV/README.md) | **Empezá acá.** Guías por tema (POO, patrones, SOLID, testing, full stack, arquitecturas, IA, cloud, criptografía), ejercicios, soluciones y simulacros |
| [material de clase/](material%20de%20clase/) | Los PDF y Word de las clases |

## Cómo usarlo

```bash
git clone <url-de-este-repo>
cd <carpeta-del-repo>/Parcial-TLP-IV
npm install          # instala TypeScript (temas 01–03)
npx tsc              # verifica que todo compile
```

Los proyectos de testing (`04-testing-vitest/...` y `10-simulacros/segundo-parcial-*`) tienen su propio `package.json`: entrá a cada uno y corré `npm install` y `npm test`.

Requisito: **Node.js 22.18 o superior**.
